#  Микропластик в океане

##  Что такое микропластик?

Микропластик — это **очень маленькие** кусочки пластика, размером меньше 5 миллиметров. Их трудно заметить глазами, потому что они меньше *семечка яблока*.

Пластик попадает в океан, постепенно ломается на мелкие части и превращается в микропластик.

> Микропластик — одна из главных проблем загрязнения океана в наше время.


##  Почему это опасно?

Рыбы и другие морские животные **путают** микропластик с едой и съедают его. Из-за этого:

1. Животные **болеют**.
2. Они **хуже** плавают и растут.
3. У них рождается **меньше** потомства.
4. Иногда они ***погибают***.

Особенно страдают маленькие рачки и рыбки, потому что они основа питания для больших животных.

| :--- | :---: |

| Атлантический океан | Много |
| Индийский океан | Средне |
| Северный Ледовитый океан | Мало |

## Как это изучают?

Учёные берут пробы воды, фильтруют её и считают частицы под микроскопом. Также они используют специальные приборы, которые определяют, из какого пластика сделана частица.
